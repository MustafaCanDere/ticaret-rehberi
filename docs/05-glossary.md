# 5. Sözlük / Glossary

| TR | EN | Açıklama / Definition |
|---|---|---|
| Aracı kurum | Broker | Yatırımcı adına alım-satım yapan lisanslı kuruluş / Licensed firm executing trades |
| Kaldıraç | Leverage | Borçla pozisyon büyütme / Using borrowed funds to enlarge a position |
| Marjin çağrısı | Margin call | Teminat yetersizse ek teminat talebi / Demand for more collateral |
| İçeriden öğrenenlerin ticareti | Insider trading | Kamuya açık olmayan bilgiyle işlem / Trading on non-public material info |
| Piyasa dolandırıcılığı | Market manipulation | Yapay fiyat/hacim yaratma / Creating artificial price or volume |
| Danışıklı işlem | Wash trade | Kendi kendine alım-satım / Trading with oneself |
| Sahte emir | Spoofing | İptal niyetli emir / Orders placed with intent to cancel |
| Aklama | Money laundering | Suç gelirini meşru gösterme / Disguising criminal proceeds |
| MASAK | FIU | Mali Suçları Araştırma Kurulu / Financial Intelligence Unit |
| KYC | KYC | Müşterini tanı / Know Your Customer |
| GTİP | HS code | Gümrük tarife kodu / Harmonized System code |
| Menşe | Origin | Malın üretildiği ülke / Country where goods originate |
| Incoterms | Incoterms | Teslim şekilleri / Delivery terms |
| Akreditif | Letter of credit | Banka ödeme garantisi / Bank-backed payment guarantee |
| Kaçakçılık | Smuggling | Gümrük kontrolünden kaçırma / Evading customs control |
| Yaptırım | Sanctions | Ülke/kişi/mal ticaret kısıtı / Trade restrictions on countries, persons, goods |
| Cayma hakkı | Right of withdrawal | Mesafeli satışta iade hakkı / Right to cancel a distance sale |
| Ponzi | Ponzi scheme | Yeni paraları eskilere ödeyen düzen / Paying old investors with new money |
| Pump & dump | Pump and dump | Şişirip satma / Hype then sell |
| Front-running | Front-running | Müşteri emrinin önüne geçme / Trading ahead of client orders |
